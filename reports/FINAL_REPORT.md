# ServeDistill：业务 OPD 最终实测报告

公开搜索业务拟真验证；Qwen3.5-9B → Qwen3.5-2B，4B 和专用 reranker 为参考。数据来自 Amazon ESCI 的真实公开 query、商品文本和独立人工标签。结果用于业务选型判断，不等于真实流量、成交、收入或完整通用能力收益。

**本轮结论：工程与实验闭环完成，候选模型未获得直接上线资格。** dev 选出的最优路径是离线 SFT；OPD 家族候选是 full_kl。两者在最终 test 的替代品域均触发 5pp 保留门，综合提升不能覆盖该域回退。没有证明 OPD 比 SFT 更适合本业务。

26 个一阶段对照和 2 个通用恢复阶段完成，两种子、每阶段 80 次 optimizer update。dev 冻结的综合候选为 **offline_sft_seed29**；OPD 候选为 **full_kl_seed17**。累计平台分配 **59.75 H20 小时**，峰值 32 卡，包含失败、加载、编译、评测和闲置驻留。

初始 2B 的业务综合分为 25.86%，通用子集为 19.67%；9B 为 50.67% / 49.50%。业务综合分是搜索 NDCG、相关性 macro-F1、替代品 macro-F1 的算术均值，不是在线成功率；通用是 GSM8K 数值答案与确定性指令任务的均值。

## 更新、损失和训练验收

\(D_{\mathrm{KL}}(p_\theta\Vert q)=\sum_v p_\theta(v\mid x,y_{<t})\log[p_\theta(v\mid x,y_{<t})/q(v\mid x,y_{<t})]\)。OPD 由 student 生成，teacher 在 student 实际前缀上评分；离线蒸馏由固定 teacher 轨迹做 CE。sampled-token 信号为 \(\mathrm{stopgrad}[\log q(y_t\mid s_t)-\log p_{\rm old}(y_t\mid s_t)]\)，不做 group 标准化，负的单 token logratio 保留。固定状态的梯度验算通过，不宣称包含前缀分布导数的完整轨迹无偏梯度。

每批 rollout/评分后更新一次参数；OPD 的信号是 token 级，GRPO 的 reward 是轨迹级。主版本是同步、single owner、lag=0，一条轨迹中不切换权重；没有异步吞吐收益证据。混合为 L_GRPO+λL_OPD；交替为更新级二选一。动态 λ 只使用 dev，限制 [0.25,4]，通用下降 3pp 时增大，业务停滞时减小。batch 混合/分桶复用相同 prompt 序列和总域预算，分桶在 10 个更新窗口内重排。token 平均与每轨迹平均分别消融。

32 项 CPU 回归通过（远程完整测试进程 exit=0）。28 个训练阶段最大 cached/recomputed 概率误差为 0.000145435，student FP32+PyTorch DeltaNet，teacher BF16；部署另以 BF16 合并。BF16 早期概率门失败触发拒绝更新，并未为了通过验收放宽该门。每阶段记录有限 gradient/参数、冻结 teacher、版本、response mask、有效 tokens、Adam/RNG checkpoint。teacher 结束指纹覆盖各参数前32元素，不能称为完整参数哈希。

监控同时查看独立 dev、reward、entropy、reference logratio、ratio/ESS/clip、梯度、JSON/截断、组内有效率与分域 tokens。非有限值或概率契约失配立即停；联合趋势报警需要 dev 复验。单独 loss 增大或 sampled KL 为负不等于崩溃。梯度 cosine 只测末层一个参数投影，不是全模型梯度冲突。

两次离线 SFT 受到监控字段缺失异常影响；seed17 从 checkpoint40 恢复 Adam/RNG，seed29 保留失败尝试后从头重跑。恢复进程 completed 的时间不能冒充80更新全程耗时。失败尝试和为 sidecar 保留的驻留时间均入总账。

## 业务迁移边界

teacher 应来自业务资格验证通过的强模型、业务 SFT/RL checkpoint 或历史通用模型。本项目使用公开 post-trained9B与版本化提示，不是独立权重专家合版。仅有文本 API 时先做离线序列蒸馏，不能假定 logits 可用。可靠 teacher 与密集行为迁移适合 OPD；可信可验证 outcome 且 teacher 不够强时优先 GRPO；高质量标签充分时保留 SFT。新商品事实通过检索与数据建设解决。

复现证据：results.json、paired/、training-curves.csv、cost-audit.json、deployment-selection.json、模型/数据契约与哈希。可视图见 domain-deltas.png 和 training-signals.png。main 保存工程与报告，manuscript 保存脱敏设计、取舍和对话摘要。
